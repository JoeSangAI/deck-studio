# 字体与字号系统

## 核心原则

先建立语义层级，再改具体文字。字体统一不等于所有文字同号；同一角色必须同字体、同字号、同粗细，
不同角色用稳定层级形成对比。

## 字体选择

- 优先使用一套可用的中文无衬线字体覆盖标题与正文，通过字重区分层级。
- 数字字体只有在图表和大数字明显受益时才单独使用；不要为了“设计感”引入第三、第四种字体。
- 交付机器没有目标字体时，先选当前环境能稳定渲染的字体，并检查 PowerPoint 实际回退结果。
- 修改现有 PPT 时，给全部可编辑文本显式写入字体；不要让一部分 run 依赖主题 `inherit`。

## 建议语义字号阶梯（16:9 商务提案）

以下是起点，不是对所有页面的强制值。每套 deck 应选一组离散值并贯穿全册：

| 角色 | 建议字号（pt） |
|------|----------------|
| 封面主标题 | 40–48 |
| 章节主标题 | 34–40 |
| 内容页主标题 | 28–32 |
| 模块/卡片标题 | 16–20 |
| 关键短句/数字 | 21–36 |
| 正文 | 12–15 |
| 辅助标签 | 9–11 |
| 来源/页脚 | 7.5–9 |

可采用类似 `7.5 / 9 / 10.5 / 12 / 13.5 / 15 / 16.5 / 18 / 21 / 24 / 30 / 36 / 44`
的离散阶梯。不要保留因跨版式缩放产生的 15.8、17.2、18.8、20.2、22.5、27.8 等碎片字号。

## 执行顺序

1. 识别封面、章节、内容标题、模块标题、正文、注释和数据数字。
2. 锁定 1–2 个字体家族和离散字号阶梯。
3. 先统一同角色，再处理个别溢出；溢出时优先调文本框、换行或布局，不为单页退回任意字号。
4. 运行 `templates/typography_audit.py`，再渲染整册检查层级和实际换行。

## 反面示例（禁止）

- ❌ 只统一主标题，正文仍由多个来源模板各自继承字体。
- ❌ 一键把全册所有文字改成同一字号。
- ❌ 为了刚好塞下而制造几十种小数点字号。
- ❌ 全篇用不支持中文的西文字体，导致中文随机回退。
- ❌ 字号统一后不重新渲染，忽略新换行和溢出。
