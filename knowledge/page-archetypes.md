# 页面类型（Page Archetypes）

## 用法

每页先归类，再选择修法。不要把所有页面都做成卡片页。

## 1. 封面 / 封底

**目标**：第一眼有识别度，标题可读。

- 保留：主标题、品牌/logo、核心视觉
- 可改：背景、标题位置、遮罩、logo 资源格式
- 禁止：低清图全屏拉伸、白字叠浅底、logo 红叉
- 验证：标题 100% 可读；logo 非 SVG/bin；背景无伪字

## 2. 章节页

**目标**：清楚分段，给观众换气。

- 保留：章节号/章节名
- 可改：背景氛围、章节号大小、留白
- 有真实场景图或明确视觉母题时，优先做成图片型章节页：全幅图 + 可控遮罩 + 大标题。标题在整册
  contact sheet 缩略图下仍须可读，并避开人物、产品、设备等主体。
- 同一 deck 的章节页共用构图骨架、遮罩强度、标题位置和字体比例，只替换场景和章节文字。
- 禁止：章节号抢走正文页信息层级
- 禁止：小图标 + 小标题漂浮在大片空白中，却把它当成“图片型章节页”
- 验证：缩略图下能看出这是章节切换，并能读出章节名

## 3. 目录 / 总览

**目标**：让结构一眼成立。

- 保留：目录项和顺序
- 可改：分栏、编号、图标、节奏线
- 当目录只有 3–5 个一级章节且整册拥有强视觉母题时，可使用图片型目录：全幅主题图承载情绪，
  目录项以高对比编号和短标题叠加，仍须保证 3 秒读出结构。
- 禁止：目录项字号过小、装饰超过内容
- 禁止：为了“稳妥”自动使用左右白色分栏，导致目录与图片型封面、章节页完全脱节
- 验证：3 秒内能读出全局结构

## 4. 策略总览

**目标**：把复杂策略分成少数清楚模块。

- 保留：每个策略名称和支撑点
- 可改：卡片宽度、层级、图文比例
- 禁止：所有文字同等字号；大黑块压迫正文
- 如果模块之间存在先后、递进或传播链路，优先使用横向阶段、流程或节奏线，不使用等权卡片假装
  它们彼此独立。
- 每个色块必须承担分组、强调或阅读路径功能；无法说明语义的色块删除。
- 验证：模块标题、图片、支撑信息层级分明

## 5. 时间轴 / 路线图

**目标**：时间、阶段、动作对齐且可读。

- 保留：日期、月份、周期、动作名称
- 可改：时间条宽度、标签换行、年度标签位置
- 禁止：标签压边框、坚持单行导致不可读
- 验证：年度/月/日期互不遮挡；窄标签可读

## 6. 方案罗列 / 对比

**目标**：让多方案差异清楚。

- 保留：方案名称、条件、预算、传播要点
- 可改：左右/上下分组、对比栏、强调条
- 禁止：把长段文字塞进小卡片；关键预算被弱化
- 验证：每个方案一眼能看出范围、节奏、成本

## 7. 数据 / 表格

**目标**：准确、可扫读。

- 保留：所有数字、单位、脚注
- 可改：表头、行距、分隔线、重点高亮
- 禁止：为了排版改数值；脚注丢失
- 验证：数字逐项保留，单位清楚

## 8. 图片案例 / 活动现场

**目标**：图片作为证据，文字作为解释。

- 保留：原图主体和说明
- 可改：图框、裁切、间距、标题位置
- 禁止：裁掉人物/会场/屏幕关键主体；图片压字
- 验证：图片比例正常，主体完整

## 9. 人物 / IP / 背书

**目标**：突出人物价值和可信度。

- 保留：人物图、姓名、身份、案例文字
- 可改：人物图大小、文案区、引导线
- 禁止：把人物裁坏、脸部被遮挡
- 验证：人物清晰，身份和价值点有层级

## 10. 密集文字页

**目标**：把文字分组，不强行海报化。

- 保留：所有段落和顺序
- 可改：小标题、编号、缩进、段距
- 禁止：删字、硬塞、字号低于下限
- 验证：正文不溢出，段落边界清楚

## 11. 图表 / 流程图

**目标**：逻辑关系清楚。

- 保留：节点、箭头、关系
- 可改：节点对齐、颜色分组、箭头层级
- 禁止：箭头压文字；节点顺序被改
- 验证：从左到右/上到下能顺读

## 12. 混合页

**目标**：先确定主信息，再让其他元素服务它。

- 主信息是数字 → 用数据页策略
- 主信息是图片 → 用图片案例策略
- 主信息是段落 → 用密集文字策略
- 主信息是时间 → 用时间轴策略

如果无法判断主信息，先减少装饰，不要新增结构。

## 13. 复杂证据 / 截图拼贴页

**目标**：保留原有证据关系，在不损失信息的前提下统一整册外壳。

- 适用：政策网页、设备结构、案例图墙、手机/电脑截图、品牌活动复盘、多标签实景拼图。
- 默认路线：`shell-unify`。冻结内部图片、标签、引导线、截图和图文对应，只处理外层标题、背景、
  安全边距、页码和必要的字体统一。
- 只有存在明确遮挡、错误对应或阅读路径断裂时才进入内部重排。
- 禁止：在顶部机械叠加统一标题；用白块/色块遮住原内容；把复杂截图页强行改成卡片模板。
- 验证：与源稿并排检查时，原证据、标签和对应关系完整；新增外壳不占用原内容安全区。
