# 场景画像（Scenario Profiles）

## 用法

拿到任意 PPT 后，先选一个主画像。画像决定视觉语气、信息优先级和检查重点，但不能改原文案事实。

## 1. 客户提案 / 销售方案

**目标**：让客户相信“方案清楚、资源靠谱、投入值得”。

- 视觉语气：商务、可信、略有高级感
- 优先强化：方案结构、时间/预算、案例背书、合作价值
- 常见页面：策略总览、方案一/二、案例图片、客户价值页
- 风险：过度装饰导致方案看不清；预算/日期被改错
- 推荐风格：暖金/深棕/暖白、克制卡片、清楚的时间轴

## 2. 内部经营汇报

**目标**：让管理者快速看懂现状、问题、动作。

- 视觉语气：冷静、克制、信息密度高
- 优先强化：指标层级、异常标记、结论先行、行动项
- 常见页面：KPI、表格、趋势图、问题清单
- 风险：做成营销页，信息被稀释
- 推荐风格：浅底、少色、强网格、清晰表格

## 3. 产品 / 品牌发布

**目标**：让产品/品牌第一眼被记住，同时逻辑完整。

- 视觉语气：更有情绪和识别度
- 优先强化：封面/章节页、产品图、卖点层级、场景图
- 常见页面：产品介绍、卖点、场景、用户/渠道、发布节奏
- 风险：AI 生成伪文字/伪包装；产品图被拉伸
- 推荐风格：提取产品色，高清无字底图 + 真实产品主体

## 4. 投资人 / 数据报告

**目标**：让数字可信、趋势清楚、逻辑严谨。

- 视觉语气：专业、准确、低装饰
- 优先强化：数据口径、图表可读、关键数字、同比/环比
- 常见页面：市场规模、财务、用户、增长、竞争格局
- 风险：为了好看改动数字或弱化脚注
- 推荐风格：浅底、深色文字、少量强调色、表格/图表对齐

## 5. 培训 / 课程材料

**目标**：让学习者跟得上、记得住。

- 视觉语气：清楚、模块化、节奏稳定
- 优先强化：章节结构、概念分层、例子、步骤
- 常见页面：目录、概念解释、流程、练习、总结
- 风险：字号太小、每页塞太多
- 推荐风格：大标题、分步编号、留白、图示

## 6. 政企 / 正式汇报

**目标**：稳重可信，符合正式场景。

- 视觉语气：庄重、规整、低风险
- 优先强化：标题层级、政策/项目结构、组织关系
- 常见页面：背景、目标、举措、时间表、成果
- 风险：过度潮流、颜色太跳
- 推荐风格：红金/深蓝/暖灰，网格严谨，少动画感

## 7. 作品集 / 案例展示

**目标**：让成果和视觉证据说话。

- 视觉语气：图像优先、编辑感、节奏变化
- 优先强化：图片质量、图组比例、案例标题、前后对比
- 常见页面：项目封面、案例网格、大图展示、人物/现场
- 风险：图片裁切丢主体；文字压图
- 推荐风格：大图 + 短标题 + 统一边距

## 8. 密集附录 / 资料包

**目标**：尽量让复杂内容不乱。

- 视觉语气：工具化、可查阅
- 优先强化：表格清晰、编号、页内索引、小标题
- 常见页面：长表、资料摘录、参数、列表
- 风险：为了美观牺牲信息完整性
- 推荐风格：浅底、细分隔线、紧凑但不低于字号下限

## 9. 现场演讲 / 课程分享

**目标**：让页面配合讲述者制造节奏、记忆点和视觉证据。

- 视觉语气：图像优先、主张鲜明、页间节奏有变化
- 优先强化：故事转折、关键判断、案例画面、章节切换
- 常见页面：大字开场、故事场景、金句、案例对比、图片墙、收束页
- 路由默认：文字已冻结的主张页优先整页图片；真实截图、视频、照片、数据和需要精确编辑的内容保留原生对象
- 风险：为了可编辑而把多数页面做成程序化版式；为了画面冲击牺牲事实、原始素材和现场播放能力
- 推荐风格：统一视觉系统下的大图、短句、明确构图；证据页保持真实素材和高可读性

## 泛化原则

- 不同画像可以共享配色，但不能共享同一排版模板。
- 先修信息结构，再修视觉气质。
- 如果页面很密，宁可朴素清楚，不要强行高级。
- 如果页面很空，才考虑加强视觉和背景。
