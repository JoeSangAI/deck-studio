# 配色方案推导

## 核心原则

**配色不是照搬，是适配**。参考色和目标场景不匹配时，要在目标场景下重新推导，借鉴参考色的"气质"而不是直接套色值。

## 4 大场景配色模板

### 1. 高端商务（客户提案 / 战略汇报）
- **主色**：香槟金 `#C9A84C` 或 暖琥珀 `#D89A3D`
- **辅色**：深棕 `#4A3F35` / 焦糖 `#3D2B1F`
- **点缀**：酒红 `#B8242A` / 朱砂 `#A03B27`
- **背景**：深底 `#1A1410` / 浅底 `#FAFAF8`
- **文字**：浅底深字 `#2C2C3A`，深底浅字 `#FFFFFF`

> 优于"商务蓝"。蓝太常见，金+棕更有"高端礼盒"感。

### 2. 科技感（产品发布 / 技术分享）
- **主色**：电光蓝紫 `#5B4FE0` / 青蓝 `#2C5F8D`
- **辅色**：深灰蓝 `#1E2530`
- **点缀**：荧光绿 `#00D4AA` / 霓虹粉 `#FF4D8B`
- **背景**：深底 `#0A0E1A`
- **文字**：浅底深字 `#1A1F2E`

### 3. 快消/大众（品牌发布 / 营销活动）
- **主色**：饱和橙 `#FF6B35` / 鲜红 `#E63946`
- **辅色**：暖黄 `#F4A261` / 米白 `#FAF0E6`
- **点缀**：天蓝 `#4A90E2`
- **背景**：浅底 `#FFFFFF` / 米色 `#F9F5F0`

### 4. 政务/国企（汇报材料 / 政企合作）
- **主色**：中国红 `#C8102E` / 国旗黄 `#FFDE00`
- **辅色**：藏蓝 `#1B3A6B` / 暖灰 `#E8E8E8`
- **背景**：浅底 `#FFFFFF`
- **文字**：深字 `#222831`

## 决策流程

```
用户给了配色参考（KV/Logo/模板）？
├─ 是 → 用 AI Vision 分析参考色的"原始场景气质"
│       ├─ 气质匹配目标场景 → 提取主色适配使用
│       └─ 气质不匹配 → 在目标场景更合适的配色方向上，借鉴参考色气质
│                       （如：KV的红+绿 → 降饱和+金过渡 → 适配高端商务）
└─ 否 → 根据场景和基调，从头推导
```

## 配色操作要点

1. **主色不超过 2 种**：主色 + 辅色足够，再多就乱
2. **点缀色克制使用**：5% 面积内的点缀才有视觉冲击
3. **背景用低饱和**：纯白 `#FFFFFF` 刺眼，暖白 `#FAFAF8` 友好
4. **文字颜色深浅匹配背景**：浅底深字、深底浅字，反差是底线
5. **HEX 大小写不重要**：但团队内统一风格

## 反面示例（禁止）

- ❌ 商务场景直接用纯蓝 `#1F4E79`（太常见，显廉价）
- ❌ 高端场景用饱和度 > 80% 的纯色（俗气）
- ❌ 一页 PPT 用 5+ 种颜色（视觉噪音）
- ❌ 浅底 + 浅字（如白底 + 浅黄字，看不清）
