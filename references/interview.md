# 访谈 → 页面规划（阶段①）

目标：用聊天补齐设计一套"打得中"的 deck 所需的信息，产出**页面规划表**（每页 id/版式/一句话内容），它直接变成大纲 HTML 的 sections。

## 访谈纪律

- **一次问 2–3 个，不甩整张表**。像访谈，不像问卷。（参考 fogg/ip-canvas 教练式节奏）
- **有素材先读再问**：用户给了文档/旧 PPT/大纲，先读，能推断的自己填，只就"推断不出的关键项"提问，并让用户确认推断。
- **目的优先**：所有信息里"期望听众做什么"最重要，先锁它，其余围绕它取舍。
- 用户说"你定"就按下方默认拍板，别反复确认。

## 必问清单（缺一不可，但能从素材推断则不问）

| # | 项 | 问法 / 要点 | 影响 |
|---|---|---|---|
| 1 | **目的·期望行动** | 讲完后，听众应该**做/信/决定**什么？ | 定全篇结论页与主线 |
| 2 | **听众** | 谁在听？懂什么、在意什么、可能质疑什么？ | 定深浅、术语、举证方式 |
| 3 | **场景** | 直播 / 线下大会 / 一对一 / 自录？现场讲解还是给人自己看？ | 定信息密度（讲解版可疏，自看版要自足） |
| 4 | **时长·页数** | 多长？→ 估页数（讲解约 1–2 分钟/页；纯图页翻得快可再宽松） | 定规模，据此拆/并页 |
| 5 | **主线结构** | 用哪条线串（见下方模板）？ | 定章节骨架 |
| 6 | **素材** | 有哪些原料：文档/数据/旧稿/真人照片/品牌规范？ | 定内容来源与锁脸页 |
| 7 | **风格基调** | 明/暗、强调色、场景域、气质（或"你定"→黑金默认） | 填 deck-config.style |
| 8 | **硬约束** | 必含页 / 品牌规范 / 保密 / 语言？ | 边界 |

## 主线结构模板（第 5 项选一条）

| 模板 | 何时用 | 骨架 |
|---|---|---|
| **线性模块** | 教学、体系介绍 | 封面 → 目录 → 模块 A/B/C（各含分隔+内容）→ 收尾 |
| **案例为线索** | 实操课、方法论落地 | 由浅入深的案例串起概念，概念在案例需要处引入（两次大课用的就是这条） |
| **问题-方案** | 提案、路演、说服 | 现状痛点 → 机会 → 方案 → 证据 → 行动 |
| **总分总** | 汇报、结论先行 | 核心主张(BIG-IDEA) → 分论点逐个证 → 回到主张收束 |
| **时间线/三阶段** | 规划、路线图 | 现在 → 近期 → 远期，或 起承转合 |
| **对比** | 选型、竞品 | 维度拆解 → 逐维对照 → 结论 |

## 从访谈到页面规划

每套 deck 的页型骨架（按主线填充）：
- **封面** `cover` → **目录** `list`(可选) → 每章 **分隔** `divider` + 若干**内容页** → 章间**转场金句** `transition` → 关键处**大主张** `big-idea` → **封底** `back-cover`
- **一页一个主要信息点**；一页塞不下就拆 a/b。页数以把事情讲清楚和现场节奏为准，不为压页数删掉必要证据，也不为显得丰富机械加页。
- 内容页按"内容形态"选版式键（数据→`stats`、要点→`bullets`、流程→`steps`、卡片→`cards`…见 [outline-schema.md](outline-schema.md) §5）
- 有真人且有本人照片 → `kol` 锁脸页；无照片不做真人页

产出示例（页面规划表，确认后转成大纲 sections）：

```
S01 cover     封面：主标题 + 副题
S02 list      目录：三章
S03 divider   第一章分隔：章标语
S04 stats     市场三数据
S05 bullets   三点论述
K01 kol       嘉宾 张三（有照片）
S06 big-idea  核心主张 + 三支柱
S07 back-cover 收尾金句
```

规划表经用户确认后，进入阶段②：套用 `assets/outline-template.html` 生成白底黑字大纲母版，逐页填文字。
